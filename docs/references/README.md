## Note on the branding discrepancy

The brand sheet describes the grai.fm site as **light**: a warm grey background
`#f0efed`, white cards with a 28 px radius, pill-shaped buttons, a bubble logo,
lime used sparingly plus pastel coral and lavender like a highlighter, and a
heavy italic serif face in the headings.

The hackathon brief describes the **opposite**: a near-black background with an
olive cast, a single lime as the only accent, a heavy white sans-serif, and a
large-circle motif.

These are two different visual languages for the same brand. **We built the
version from the brief** (the dark one). The brand sheet itself calls this a
decision for the team to make.
